# Подходы в карточках и перестановка суперсетов

Ветка: `agent/workout-cards-superset-order`.

## Запуск

```bash
cd /Users/rb/Sources/mighty-cringe
pnpm local:dev
```

Приложение: <http://localhost:5173/>. API health: <http://127.0.0.1:3000/health>.
Если локальные сервисы уже работают, достаточно открыть ссылку; сбрасывать базу не нужно.

## Проверка владельцем

1. Открыть тренировку с несколькими суперсетами и одиночным упражнением на пресс внизу списка.
   Добавить прессу три подхода. Все три должны быть видны прямо в карточке, без объединения
   в суперсет. Добавить ещё подходы: новые ряды остаются внутри карточки и доступны при прокрутке.
2. Нажать на последний подход в карточке: форма показывает его вес, повторы и RIR.
   Закрыть форму и открыть само упражнение: количество и значения подходов совпадают.
3. В трёх парах `[A B][C D][E F]` открыть меню E → «Поднять выше». Получается
   `[A B][C E][D F]`: три связки по два упражнения, подходы следуют за своими упражнениями.
   Повторить вверх/вниз внутри пары и через границу пары. Связки разделяются только отдельным
   действием «Разделить связку здесь».
4. Обновить страницу. Порядок, связки и подходы сохраняются.
5. Проверить стрелки также в плане до старта и через «Править» у завершённой тренировки.
   Одиночные карточки с подходами в истории также не должны обрезаться.

Исправление не меняет семантику относительных текстовых команд «перед/после».
Перед merge требуется локальная проверка владельца согласно `AGENTS.md`.

## Проверено агентом

- Воспроизведено исходное перекрытие: высота одиночной карточки около 67 px, нижняя граница
  подходов ниже карточки; у суперсета дефект отсутствует.
- После исправления проверены 320×640, 360×800, 390×844 и 440×956: все подходы внутри
  карточек, список прокручивается, горизонтального переполнения нет.
- На синтетической локальной тренировке проверены семь подходов у одиночного пресса,
  открытие последнего подхода и сохранение восьмого через форму.
- Обмен пятого упражнения между тремя суперсетами и перезагрузка сохраняют три пары,
  состав и количество подходов. После чистой перезагрузки ошибок консоли нет.
- В режиме «Править» завершённой синтетической тренировки проверены все восемь подходов
  одиночного пресса, открытие последнего подхода и обратный обмен между второй и третьей парой.
- `pnpm test`, `pnpm lint`, `pnpm typecheck` пройдены. Форматирование изменённых файлов
  проходит; общий `pnpm format:check` отмечает ранее существующий игнорируемый
  `.claude/settings.local.json`, который не изменялся.
  Пять интеграционных тестов PostgreSQL пропущены стандартным запуском без `DATABASE_URL`.
