# Прошлый результат в карточке упражнения

Владелец прошёл локальную проверку и разрешил merge 2026-11-09.

## Запуск

```bash
cd /Users/rb/Sources/mighty-cringe
git switch main
pnpm local:dev
```

Приложение: http://localhost:5173. Health API: http://localhost:3000/health.

## Проверка

1. В локальном журнале завершить тренировку с тремя подходами одного упражнения:
   80 кг × 8, 80 кг × 8, 80 кг × 7.
2. Добавить это упражнение в следующий план. Под карточкой должна появиться дата прошлого
   выполнения и «80 кг × 8 / 8 / 7» без открытия формы. У нового упражнения строки нет.
3. Начать тренировку: строка остаётся, новые подходы отображаются отдельно и не меняют
   прошлый результат. Открыть форму — её прошлая история должна совпасть с карточкой.
4. Проверить упражнение с разными весами: каждый вес сохранён, порядок не изменён.
5. В редакторе старой тренировки сравнение идёт только с более ранней тренировкой.
   Удалённые подходы и незавершённые тренировки не должны попадать в строку.
6. После загрузки истории отключить сеть и обновить приложение: прошлые результаты доступны
   из локальных данных. На узком экране длинная строка переносится, карточки не перекрываются.
7. В английском интерфейсе и фунтах подпись и единицы соответствуют настройкам.

Автоматическая проверка: `pnpm --filter @mighty-cringe/web test` и
`pnpm --filter @mighty-cringe/web build`. Они не заменяют локальную приёмку владельца.
