## Приёмка

1. Открыть упражнение из плана, затем из каталога. В обоих случаях сверху одна и та же
   панель с шевроном и названием раздела; кнопка возвращает в соответствующий исходный экран.
2. Прокрутить длинную карточку до конца: шеврон остаётся на месте под шапкой приложения.
   На узком экране длинное название не обрезает элементы справа.
3. Открыть «Настройки → Язык и единицы измерения», вернуться шевроном.
   Проверить «Аудиокоманды → Записи команд»: возврат ведёт сначала в аудиокоманды, затем в настройки.
4. В каталоге ввести несуществующее название, открыть форму создания и вернуться к вариантам
   добавления. Сохранять тестовое упражнение не нужно.
5. Если доступен личный каталог или роль тренера, проверить тот же возврат в редакторе
   упражнения и по пути «Настройки → Подопечные → Ученик».

## Проверка агента

Пройдены 248 web-тестов, web-сборка с typecheck, PWA offline-shell, форматирование изменённых
файлов и `git diff --check`. В браузере проверены карточки из плана
и каталога, длинное название, закрепление панели при прокрутке, подраздел настроек и
возврат через два уровня аудиокоманд. На ширине 320 px область нажатия остаётся 48×48,
ширина содержимого равна доступной ширине. Данные профиля и тренировок при проверке не менялись.
В форме создания проверен возврат при фокусе в поле без сохранения упражнения.

Проверка роли тренера ограничена кодом и существующим компонентным тестом:
локальный пользователь имеет роль спортсмена.
