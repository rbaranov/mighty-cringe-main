# Компактный итог и возврат по тексту

Ветка: `agent/workout-results-navigation`. Локальная версия: <http://localhost:5173/>.
API: <http://127.0.0.1:3000/health>.

## Запуск

```bash
cd /Users/rb/Sources/mighty-cringe
pnpm local:dev
```

## Приёмка

1. На плане выбрать «Итог последней тренировки». Проверить верхние кнопки выхода,
   прогресса, редактирования и избранного. Вернуться к плану и открыть итог снова.
2. В «Прогрессе» открыть последний итог, затем выбрать другую тренировку через
   «История → день → Итог». «Назад» возвращает в прогресс.
3. В итоге нажать «Править», затем «Готово»: снова виден итог этой тренировки.
   Обновить страницу — итог остаётся открытым.
4. Проверить компактную сводку, раскрыть рекорды и строку упражнения: исходные подходы,
   предыдущая дата и сравнение повторов доступны. На коротком экране и при раскрытии
   подробностей разрешена вертикальная прокрутка; верхние действия остаются доступными.
5. В «Настройки → Язык и единицы измерения» нажать на текст рядом со стрелкой.
   Повторить в карточке упражнения и форме добавления с открытой клавиатурой.
