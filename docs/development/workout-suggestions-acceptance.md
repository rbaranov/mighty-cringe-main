`agent/personal-workout-shuffle` и этого сценария. Подбор работает с данными текущего журнала,

Health: [API](http://127.0.0.1:3000/health). Не запускайте второй `local:dev`, пока работает первый.

## Сценарий владельца

1. На главной без активной тренировки проверьте: избранные тренировки сверху, ниже — весь
   «План на сегодня», кнопка старта и упражнения. Если избранного нет, экран начинается с плана.
2. Нажмите «Другой вариант» несколько раз. Состав должен меняться, если в каталоге есть
   альтернативы. Упражнения не дублируются, их не больше шести. Отметки «не нравится» исключены.
3. Частые упражнения с записанными подходами, лайки и состав избранных повышают шанс выбора,
   но не закрепляют упражнения навсегда. Если истории нет, работает обычный случайный подбор.
4. Перезагрузите страницу: последний выбранный вариант должен сохраниться. При желании
   измените состав вручную, затем начните тренировку — откроется именно показанный план.
   Во время активной тренировки кнопки перегенерации нет.
5. На телефоне проверьте читаемость названий избранного и доступность «Повторить»,
   «Другой вариант» и «Начать тренировку».

«Другой вариант» заменяет весь черновик, включая ручные правки и связки. Если других сочетаний
нет, появится пояснение; доступный состав не сокращается ради формального изменения.

## Выполненные проверки агента

- 297 web-тестов, в том числе 14 тестов подбора: частота по выполненным подходам, лайки,
  избранное, дизлайки, малый/пустой каталог, отсутствие дублей и смена состава.
- Web typecheck, production build и проверка PWA offline-shell.
- Браузер: смена состава, сохранение после перезагрузки и запуск показанного плана;
  избранное выше плана, 320/360 px без горизонтального переполнения, консоль без ошибок.
- Изолированный локальный прокси возвращал 503 для API: план менялся, сохранялся,
  восстанавливался после перезагрузки и снова менялся в режиме «Сервер недоступен».
  Это проверка недоступного backend; полное отключение сети в установленной PWA отдельно
  не имитировалось. Прокси после проверки остановлен, обычный локальный сервер оставлен доступным.

Для визуальной проверки в локальном тестовом аккаунте сохранена синтетическая избранная
тренировка «Тест подбора» без подходов; она не увеличивает статистику.
